Gateway Conditioner for WooCommerce

Official User Guide & Technical Documentation for conditional payment gateway management in WooCommerce.

Version 2.2.0 WordPress 5.8 to 7.1+ WooCommerce 6.0 to 9.9+ HPOS Compatible Checkout Blocks Ready

1. Overview

Gateway Conditioner for WooCommerce gives store administrators complete, granular control over which payment gateways appear at checkout. Build flexible IF → THEN rules evaluated sequentially in real time with support for multi-condition AND groups across 7 condition types.

The plugin operates with zero performance penalty using in-memory request memoization and preloaded shipping zones, guaranteeing instant checkout evaluation.

2. Requirements

  • WordPress: 5.8 or higher (fully tested up to WordPress 7.1+)
  • WooCommerce: 6.0 or higher (fully tested up to WooCommerce 9.9+)
  • PHP: 7.4 or higher (supports PHP 8.0, 8.1, 8.2, 8.3+)
  • High-Performance Order Storage (HPOS): Supported
  • WooCommerce Cart & Checkout Blocks: Supported

3. Installation Guide

Method A: Standard WordPress Dashboard Upload (Recommended)

  1. Download the installable plugin zip file: gateway-conditioner-for-woocommerce.zip.
  2. Log into your WordPress admin dashboard.
  3. Go to Plugins → Add New → Upload Plugin.
  4. Click Choose File, select gateway-conditioner-for-woocommerce.zip, and click Install Now.
  5. Once installed, click Activate Plugin.

Method B: FTP Upload

  1. Unzip gateway-conditioner-for-woocommerce.zip on your computer.
  2. Upload the unzipped gateway-conditioner-for-woocommerce folder to your web server in the directory: /wp-content/plugins/.
  3. Go to Plugins → Installed Plugins in WordPress and activate Gateway Conditioner for WooCommerce.
Note: WooCommerce must be installed and activated before activating this plugin.

4. Creating Payment Rules

Navigate to WooCommerce → Payment Rules in your WordPress admin menu.

Rule Anatomy

Each rule consists of two parts:

  1. IF (Condition Group): One or more conditions that must be satisfied.
  2. THEN (Action): The payment gateway to disable if the conditions are met.

Adding AND Conditions

Click the Add AND Condition button within any rule card to require multiple criteria simultaneously (e.g. If Cart Total > $500 AND Shipping Method is Local Pickup → Disable Cash on Delivery).

Supported Condition Types

Condition Type Operators Description
Product Category is, is not Triggers when items from specific product categories are in the cart. Automatically inherits child sub-categories.
Specific Product is, is not Targets individual products or variations by title, SKU, or ID.
Cart Total >, >=, <, <=, is, is not Evaluates against the order total or subtotal amount.
User Role is, is not Targets customer roles (e.g. Wholesale, Customer) or Guest shoppers.
Shipping Method is, is not Evaluates the selected shipping rate or zone (e.g. Local Pickup vs Flat Rate).
Billing Country is, is not Evaluates customer billing location with fallback to shipping country.
Order Quantity >, >=, <, <=, is, is not Evaluates the total number of items in the customer cart.

6. Troubleshooting & FAQs

Q: Why does a payment gateway still appear after creating a rule?
Ensure that all AND conditions inside the rule are met. If a rule has multiple conditions, every condition must evaluate to true for the gateway to be disabled.

Q: Is this plugin compatible with WooCommerce HPOS?
Yes. The plugin declares official compatibility with custom order tables (HPOS) and does not perform legacy post queries on orders.

Q: Does this plugin work with WooCommerce Blocks checkout?
Yes. The plugin filters gateways via the standard WooCommerce available payment gateways API, which is utilized by both shortcode checkout and Cart & Checkout Blocks.
